Yes — these changes make the Data Protection key path platform-independent.

This code:

var keyPath = Path.Combine(
    Environment.GetFolderPath(Environment.SpecialFolder.UserProfile),
    ".aspnet-keys");

Directory.CreateDirectory(keyPath);

builder.Services.AddDataProtection()
    .SetApplicationName("TemplateHost")
    .PersistKeysToFileSystem(new DirectoryInfo(keyPath));

works correctly on:

Linux
macOS
Windows

because .NET automatically resolves the proper home directory:

Linux:

/home/ken

macOS:

/Users/juderemedios

Windows:

C:\Users\Ken

So your Data Protection cookie encryption system is now portable.

However, your overall app is only platform
